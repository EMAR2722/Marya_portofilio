# Marya Getu Portfolio (Next.js)
1. `npm install` then `npm run dev` and open http://localhost:3000
2. Contact form: get a free key at https://web3forms.com (use maryagetu04@gmail.com), copy `.env.example` to `.env.local` and paste the key.
3. Edit text, projects and links in `lib/data.ts`. Replace images in `public/`.
4. Deploy: push to GitHub, import the repo on vercel.com, add `NEXT_PUBLIC_WEB3FORMS_KEY` under Environment Variables, deploy.
